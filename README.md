# BetterMac

A customization suite for your Mac — turns the notch into a Dynamic Island and adds live wallpapers, face recognition, a file shelf, clipboard history, weather and more.

## Install
Download **BetterMac.zip** from the latest [release](https://github.com/wersxyy/BetterMac/releases/latest), unzip, and move **BetterMac.app** to your Applications folder. On first launch, right-click the app and choose **Open**.

Updates install themselves automatically.
